# FUTURE_DS_01
Business Sales Performance Analytics using Microsoft Excel with interactive dashboards and data-driven insights.

## Project Overview

This project analyzes Superstore sales data to understand business sales and profit performance. The analysis focuses on sales trends, top-performing products, categories, and regions.

The project was completed using Microsoft Excel with formulas, PivotTables, PivotCharts, slicers, and dashboard formatting.

## Objectives

- Analyze overall sales and profit performance
- Identify top-selling products
- Understand monthly sales trends
- Compare sales across categories and regions
- Identify profitable categories and regions
- Create an interactive business dashboard
- Provide useful business insights and recommendations

## Dataset

The project uses the Superstore Sales Dataset containing information such as:

- Order ID
- Order Date
- Ship Date
- Customer details
- Region
- Category
- Sub-Category
- Product Name
- Sales
- Quantity
- Discount
- Profit

## Data Preparation

The dataset was prepared using Microsoft Excel. The following steps were performed:

- Checked the data for missing and inconsistent values
- Removed unnecessary records where required
- Corrected date formatting
- Created Year-Month and Year helper columns
- Organized the data for PivotTable analysis

## Dashboard

An interactive Excel dashboard was created to provide a clear overview of business performance.

The dashboard includes:

- KPI cards
- Monthly sales trend
- Top 10 products by sales
- Sales by category
- Sales by region
- Profit by category
- Profit by region
- Region and Category slicers

## Key Insights

- Technology was the highest-sales category.
- The West region generated the highest profit.
- Sales performance varies across different categories and regions.
- Top-performing products contribute significantly to overall sales.
- Interactive slicers make it easier to compare business performance.

## Recommendations

- Focus on high-performing products and categories to support sales growth.
- Analyze lower-performing regions and categories to identify improvement opportunities.
- Monitor both sales and profit when evaluating business performance.
- Use the dashboard regularly to track changes in sales and profitability.
